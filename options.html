Shortcuts, macros and page gestures.

Your shortcuts & macros

Pick a key combination, then choose what it should do. Add a second step and it becomes a macro — one key, several changes at once. These work on any page you're reading.

Built-in browser shortcuts

These are registered with the browser itself, so they keep working even where a page blocks key presses. Only the browser can change them.

Mouse gestures

Shortcuts you make with the pointer instead of the keyboard.

Gestures are part of your all-sites settings. A site you've given its own settings to uses whatever is set there.
